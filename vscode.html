VS Code : quand tu en as besoin, et quand non

Tu veux créer ton site avec l'IA, et on te dit d'installer VS Code ? Pour démarrer, ce n'est pas ce qu'il te faut. Ce qu'il te faut, c'est Claude Code. VS Code, c'est un éditeur gratuit qui affiche tes fichiers : utile plus tard, quand ton projet grossit.

Pour démarrer : l'appli Claude, onglet Code

  1. Télécharge l'appli Claude sur claude.com/download, pour Mac ou Windows, et connecte-toi.
  2. Ouvre l'onglet Code et choisis le dossier de ton projet sur ton ordinateur.
  3. Décris ce que tu veux, en français. Claude Code crée et modifie les fichiers dans ce dossier.

Claude Code demande un forfait payant (Pro ou Max). Pas de VS Code à installer pour ça.

1Deux outils, deux rôles

VS Code, l'atelierUn éditeur de code de Microsoft, gratuit pour un usage privé comme professionnel, sur Mac, Windows et Linux.
Claude Code, celui qui construitIl tourne dans le terminal, dans l'appli Claude, ou dans VS Code grâce à l'extension officielle d'Anthropic.

Le code produit est le même dans les trois cas. VS Code ne fait pas coder Claude mieux. Il te fait, toi, mieux voir et mieux piloter.

2Ce que l'extension t'apporte

  • Les modifications côte à côte. L'original à gauche, sa proposition à droite.
  • Accepter ou refuser chaque changement, un par un.
  • Relire et corriger son plan avant qu'il passe à l'action.
  • Lui montrer un fichier précis avec @, même quelques lignes seulement.
  • Plusieurs conversations en onglets, une par chantier.

3Quand tu n'en as pas besoin

Pour démarrer, rien d'obligatoire. Moi-même, je travaille surtout en Claude Code direct. Tu peux t'en passer si :

  • tu débutes,
  • ton projet tient en quelques fichiers,
  • tu fais surtout du texte, des documents, des tâches de bureau.

4Les 5 signaux pour passer à VS Code

Pas de chiffre magique. Tu passes à VS Code quand le projet ne tient plus dans ta tête :

  • Une vraie arborescence, des dizaines de fichiers rangés dans des dossiers.
  • Tu ajustes du visuel et tu relances le rendu dix fois.
  • Tu commences à toucher le code toi-même, même un petit réglage.
  • Tu reviens sur le projet plusieurs jours de suite.
  • Tu te perds : tu ne sais plus où est quoi, ni ce qui a changé.

L'installer en 3 étapes

  1. Télécharge VS Code uniquement sur code.visualstudio.com. Il faut la version 1.94 ou plus récente.
  2. Ouvre les extensions (Cmd + Maj + X sur Mac, Ctrl + Maj + X sur Windows), cherche « Claude Code », vérifie qu'il est publié par Anthropic, puis Installer.
  3. Clique sur l'icône en forme d'étincelle en haut à droite d'un fichier ouvert, et connecte-toi avec ton compte Claude (forfait payant).

Et pour mettre ton site en ligne une fois construit, c'est une autre étape : publier ton premier site.
