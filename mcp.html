Brancher un MCP en toute sécurité

MCP veut dire Model Context Protocol. C'est un standard ouvert pour relier une IA à tes outils, que ses créateurs comparent à une prise USB-C. Une fois branché, Claude lit et agit directement dans l'outil. Voici comment le brancher sans ouvrir la porte à n'importe quoi.

Les deux risques

Tes données chez un tiersUn connecteur hébergé ailleurs, c'est un service qui voit passer ce que Claude lui envoie. Anthropic ne contrôle pas comment un connecteur tiers traite tes données.
Des instructions cachéesUn serveur MCP malveillant peut glisser des consignes cachées pour pousser Claude à faire autre chose que ce que tu as demandé. On appelle ça une injection d'invite. Et un MCP que tu télécharges, c'est en plus du code qui tourne chez toi.

1Lis l'étiquette

L'annuaire des connecteurs de Claude affiche trois niveaux :

  • Vérifié (une coche). Anthropic a testé ses outils. Ce n'est pas pour autant un audit de sécurité ni une garantie : le développeur peut changer ses outils après.
  • Communauté. Fait par un développeur tiers, filtré par Anthropic mais pas examiné en profondeur.
  • Personnalisé. Tu l'as ajouté toi-même avec son adresse. Anthropic ne l'a pas examiné du tout.

2Les 5 vérifications avant de brancher

  • Qui le développe ? Uniquement des organisations en qui tu as confiance. Idéalement, l'éditeur de l'outil lui-même.
  • Les autorisations demandées. À la connexion, lis ce qu'il demande. Refuse ce qui semble inutile.
  • Lecture ou écriture ? Désactive les outils dont tu n'as pas besoin, surtout ceux qui peuvent écrire ou envoyer.
  • « Toujours autoriser » avec parcimonie. Seulement pour un serveur et un outil de confiance.
  • Un MCP à télécharger ? Même audit qu'un repo : vérifier un repo.

3Le pas à pas

Dans l'appli Claude : Personnaliser, puis Connecteurs. Clique « + Ajouter », puis « Ajouter un connecteur personnalisé ». Donne un nom et l'adresse du serveur, puis « Ajouter ». Ensuite, tu l'actives conversation par conversation avec le bouton « + ». Sur le gratuit, un seul connecteur personnalisé.

Pour le retirer : Personnaliser, Connecteurs, puis « Supprimer » ou les trois points à côté du connecteur.

Dans Claude Code : l'exemple officiel, avec le serveur de Notion :

claude mcp add --transport http notion https://mcp.notion.com/mcp

Tape /mcp pour voir l'état de tes serveurs, et claude mcp remove notion pour en retirer un. Si un projet que tu as téléchargé contient ses propres serveurs (fichier .mcp.json), Claude Code te demande ton accord avant de les lancer. Lis la demande avant d'accepter.

Les 3 réflexes

  1. L'officiel d'abord. Le connecteur de l'éditeur, ou un connecteur vérifié.
  2. Le minimum d'accès. Juste ce dont la tâche a besoin.
  3. Débranche ce que tu n'utilises plus. Un accès inutile reste un accès.
