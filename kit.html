1Le lexique, les mots qu'on te balance

Claude
Une IA, comme ChatGPT. Sérieuse sur l'écriture, le raisonnement et le code.
Claude Code
Claude installé sur ton ordi, qui agit (lit, écrit, exécute) au lieu de juste répondre.
Modèle
Une version de Claude. Opus (le plus malin), Sonnet (l'équilibré), Haiku (le plus rapide).
Token
Un bout de mot (environ ¾ d'un mot). L'IA lit et écrit en tokens, et c'est ce qui est facturé.
Fenêtre de contexte
La quantité de texte qu'elle garde en tête. Au-delà, elle « oublie » le plus ancien.
Prompt
Ta consigne. Bonne recette : rôle + contexte + format voulu.
Hallucination
Quand l'IA invente une info qui a l'air vraie. Vérifie toujours ce qui engage ta responsabilité.
Fichier .md (markdown)
Du texte simple et structuré (titres, listes). L'IA adore.
CLAUDE.md
Le fichier de tes instructions permanentes : ton activité, ton style, tes règles.
Mémoire
Des fichiers où Claude note ce qui compte, pour te reconnaître d'une fois sur l'autre.
Skill
Une compétence toute prête que tu donnes à Claude (audit SEO, présentation, mail de prospection…).
MCP
Une prise entre Claude et tes outils (Gmail, Slack, une base de données…).
Hook
Un réflexe automatique : « à chaque fois que X, fais Y ».

2Les vraies peurs

Claude va accéder à tous mes fichiers ?

Non. Uniquement aux dossiers que TU lui montres, et il demande la permission avant chaque action.

Je vais me faire pirater en l'installant ?

Claude vient d'Anthropic, ce n'est pas un virus. Le seul truc à vérifier, ce sont les skills tiers que tu ajoutes.

Faut savoir coder ?

Non. Pour commencer, le chat sur claude.ai suffit. Claude Code est plus technique, mais on peut débuter sans être développeur.

Ça coûte cher ?

Le chat sur claude.ai a une version gratuite pour découvrir. Claude Code, lui, demande un abonnement payant : la version gratuite n'y donne pas accès. Tu paies quand tu passes à un usage sérieux.

L'IA se trompe, non ?

Parfois, oui. Tu gardes le contrôle : tu vérifies ce qui engage ta responsabilité. Jamais d'automatisation aveugle.

Ne télécharge jamais depuis un lien au hasard trouvé dans un reel. Toujours le site officiel.

Installer Claude Code en une commande, pour les plus à l'aise.
Mac ou Linux, dans le Terminal :

curl -fsSL https://claude.ai/install.sh | bash

Windows, dans PowerShell :

irm https://claude.ai/install.ps1 | iex

Ensuite, tape claude : ton navigateur s'ouvre pour te connecter.

4Les 5 bonnes pratiques qui comptent

  1. Ne colle jamais ta clé API, tes mots de passe ou tes données sensibles dans un chat.
  2. Vérifie un skill ou un outil tiers avant de l'installer : qui l'a fait, que fait-il ?
  3. Garde la main : Claude demande la permission, lis avant de valider.
  4. Commence petit : automatise UNE tâche répétitive, pas tout d'un coup.
  5. Une consigne claire = un bon résultat : rôle + contexte + format.

Et maintenant ?

Passer de « je comprends » à « ça me fait gagner des heures », ça se joue sur TON activité, tes tâches, tes chiffres. C'est exactement ce que je fais avec les entreprises : je chiffre ce que tes tâches répétitives te coûtent, et je t'accompagne pour les réduire. Sans jargon, sans dépendance.
