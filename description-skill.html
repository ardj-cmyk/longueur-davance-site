La description qui fait lancer ton skill

Ton skill peut être parfait : si sa description est floue, Claude ne l'ouvre jamais. Tout se joue en deux lignes, tout en haut du fichier. Voici ma méthode pour les écrire.

Comment Claude choisit

Il ne lit que la descriptionLes descriptions de tous tes skills sont chargées en permanence. Le reste du fichier SKILL.md n'est lu qu'une fois le skill choisi. Tant que la description ne correspond pas à ta demande, ton beau travail dort.
Les limites de longueurSur claude.ai, le nom fait 64 caractères maximum et la description 200. Dans Claude Code, la description est coupée au-delà de 1 536 caractères : mets l'essentiel au début.

1La formule

Une bonne description dit deux choses : ce que fait le skill, et quand l'utiliser. Avec les mots que tu emploies vraiment.

[Verbe d'action] [ce qu'il produit] à partir de [ce que tu lui donnes].
À utiliser quand je parle de [mot 1], de [mot 2] ou de [mot 3].

Dans le fichier, ça donne :

---
name: redaction-devis
description: Rédige un devis à partir de mes notes d'appel. À utiliser quand je parle de devis, de chiffrage ou de proposition.
---

2Avant, après

Ne se lance jamais« Aide pour les devis. »
Se lance au bon moment« Rédige un devis à partir de mes notes d'appel. À utiliser quand je parle de devis, de chiffrage ou de proposition. »
Trop vague« Comptes rendus. »
Précis« Transforme mes notes de chantier en compte rendu client d'une page. À utiliser quand je parle de compte rendu, de CR ou de point chantier. »

3Le test des 5 phrases

  1. Écris 5 demandes comme tu les formules vraiment, un mardi pressé : « fais-moi le chiffrage pour Dupont ».
  2. Lance-les une par une, dans une conversation neuve.
  3. Le skill ne s'ouvre pas ? Ajoute dans la description le mot que tu as employé.
  4. Il s'ouvre quand il ne devrait pas ? Rends la description plus précise.

Toujours rien ? Les vérifications officielles

  1. Demande à Claude « Quels skills sont disponibles ? » pour voir s'il le connaît.
  2. Appelle-le directement avec /nom-du-skill dans Claude Code.
  3. Vérifie l'en-tête : les trois tirets doivent être sur la toute première ligne. Si l'en-tête est mal formé, Claude ne peut pas lire la description.

Avant d'installer le skill de quelqu'un d'autre, vérifie qui l'a écrit et ce qu'il fait : repérer l'arnaque en dix secondes.
