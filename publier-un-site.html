Publier ton premier site

Ton site marche sur ton ordinateur. Pour qu'il soit en ligne pour le monde entier, avec une vraie adresse, tu passes par un hébergeur comme Vercel. Voici le chemin le plus simple, et le piège à connaître si c'est le site de ton entreprise.

Ce que fait Vercel

Chaque mise en ligne reçoit automatiquement une adresse qui finit par .vercel.app, tirée du nom de ton projet. Toute personne à qui tu donnes le lien voit ton site. Ensuite, tu peux brancher ton propre nom de domaine dans les réglages du projet (Settings, puis Domains).

Le piège : le gratuit, c'est pour le persoL'offre gratuite de Vercel (Hobby) est réservée à un usage personnel et non commercial. Est commercial, par exemple, un site qui fait la promotion d'un produit ou d'un service, qui encaisse des paiements, qui affiche de la pub, ou que quelqu'un est payé pour créer. Le site de ton activité entre dans ce cas : il faut l'offre Pro, à 20 $ par développeur et par mois, hors taxes.

1Le plus simple : avec Claude Code

Ouvre Claude Code dans le dossier de ton site, et demande :

Publie ce site sur Vercel.
Installe ce qu'il faut, explique-moi chaque étape
avant de la lancer, et donne-moi l'adresse en ligne à la fin.

Il fera, en gros, ce que décrit la documentation de Vercel :

npm i -g vercel
vercel login
vercel
vercel --prod

Installer l'outil, te connecter à ton compte Vercel, publier une version d'aperçu, puis la version définitive. Il faut Node.js 18 ou plus récent, Claude Code peut te l'installer.

2L'autre chemin : depuis GitHub

  1. Ton site est sur GitHub ? Va sur vercel.com/new.
  2. Connecte ton compte GitHub, choisis le dépôt, clique « Deploy ».
  3. C'est en ligne. Et chaque modification envoyée sur GitHub remet le site à jour automatiquement.

3Les alternatives

  • Netlify Drop (app.netlify.com/drop) : tu glisses le dossier de ton site, il est en ligne tout de suite, même sans compte. Sans compte, les fichiers sont publiés tels quels : si ton site doit être construit avant, dépose le dossier final (souvent dist ou build). Connecté, Netlify sait lancer la construction pour toi.
  • Cloudflare : sa documentation conseille désormais Workers plutôt que Pages pour un nouveau projet.

Avant d'envoyer le lien

  1. Aucune clé ni mot de passe dans les fichiers du site. Tout ce qui est publié est lisible. Où ranger une clé.
  2. Le bon forfait si le site sert ton activité.
  3. Ouvre l'adresse sur ton téléphone. C'est là que la plupart des gens le verront.
