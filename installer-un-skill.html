Installer un skill sans risque

Un skill, c'est une compétence que tu ajoutes à Claude : des instructions, et parfois des scripts qui s'exécutent. Anthropic l'écrit noir sur blanc dans son aide : n'installe des skills que depuis des sources fiables. Voici comment faire le tri.

Le cas qui montre pourquoi

book-to-skill, août 2026Un skill populaire a été recopié par un autre compte GitHub, sous le même nom. D'après l'avis de sécurité publié le 17 août par l'auteur original, la copie désactivait la vérification des certificats, envoyait les informations de la machine vers un serveur externe, fouillait les données de portefeuilles de cryptomonnaies, et sur Windows embarquait un programme qu'elle pouvait lancer toute seule. Les gens ont été piégés parce que la copie ressemblait exactement à l'original.

1D'abord, les skills officiels

  • Dans l'appli Claude, Anthropic fournit déjà des skills pour Excel, Word, PowerPoint et PDF. Claude s'en sert tout seul quand ta demande s'y prête. Il faut que l'exécution de code soit activée : Paramètres, puis Capacités.
  • Pour voir, activer ou ajouter des skills : Personnaliser, puis Compétences.
  • Dans Claude Code, le dépôt officiel d'Anthropic s'ajoute avec cette commande :
/plugin marketplace add anthropics/skills

Anthropic présente ces skills comme des exemples, à tester avant de t'y fier pour une tâche importante.

2Pour tous les autres, l'audit en 6 points

C'est la version simplifiée de la liste qu'Anthropic donne aux entreprises :

  • La provenance. Qui l'a fait, et est-ce le bon compte ? La méthode : vérifier un repo.
  • Tout le dossier, pas seulement SKILL.md. Les scripts (.py, .sh, .js) s'exécutent avec un accès complet à ton environnement.
  • Les appels vers internet. Une adresse web, curl, fetch, requests : c'est une porte de sortie possible pour tes données.
  • Les consignes louches. Ignorer les règles de sécurité, cacher une action, envoyer des données : on n'installe pas.
  • Aucun mot de passe ni clé écrit dedans.
  • Dans Claude Code, le champ allowed-tools. Il liste les outils que Claude peut utiliser sans te demander quand le skill est lancé. Relis-le avant de l'utiliser.

3Fais-le vérifier par Claude, à chaque fois

Écris la règle une fois dans ton fichier CLAUDE.md, ou dans les instructions d'un projet :

Avant d'installer le moindre skill, audite-le :
qui l'a fait, ce que font ses scripts,
s'il contacte internet, s'il lit des fichiers hors de son dossier.
Ne me propose l'installation qu'après ton verdict.

Pour aller plus loin, un hook peut rendre cette vérification obligatoire : des exemples de hooks.

Tu as déjà installé un skill douteux ?

  1. Ne le relance pas. Désactive-le dans Personnaliser, Compétences, ou avec /plugin dans Claude Code.
  2. Un portefeuille crypto sur la machine ? Suis la procédure de récupération de ton éditeur, depuis un autre appareil.
  3. Change les mots de passe enregistrés dans ton navigateur, depuis un appareil sain.
