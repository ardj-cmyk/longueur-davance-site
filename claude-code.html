Installer Claude Code, pas à pas

Claude Code, c'est Claude qui ne se contente plus de te répondre : il agit sur les fichiers de ton ordinateur. Il les lit, les modifie, en crée, et te demande la permission avant. Voici comment l'installer et faire tes premiers pas.

Avant de commencer

  • Un forfait payant (Pro, Max, Team ou Enterprise). Claude Code n'est pas dans le gratuit.
  • Un dossier de test. Pour tes premiers essais, crée un dossier vide sur ton bureau. Tu ne risques rien.

Trois façons de l'utiliser

Dans l'application Claude · le plus simple

Sur ordinateur, l'application Claude intègre Claude Code. Aucune commande à taper.

Dans le navigateur · rien à installer

Sur claude.ai/code, il travaille sur tes projets en ligne.

Dans le terminal · le plus puissant

La version d'origine. C'est celle qu'on installe ci-dessous.

L'installer dans le terminal

  1. Ouvre le terminal. Sur Mac : la loupe en haut à droite, tape « Terminal ». Sur Windows : menu Démarrer, tape « PowerShell ».
  2. Colle la commande de ton système et appuie sur Entrée.

    Mac ou Linux

    curl -fsSL https://claude.ai/install.sh | bash

    Windows (PowerShell)

    irm https://claude.ai/install.ps1 | iex
    L'installation n'affiche rien pendant le téléchargement, c'est normal.
  3. Ferme et rouvre le terminal, puis vérifie : 
    claude --version
    Un numéro de version s'affiche ? C'est installé.
  4. Va dans ton dossier de test et lance Claude Code : 
    cd Desktop/test
claude
  5. Connecte-toi. Au premier lancement, ton navigateur s'ouvre : connecte-toi avec ton compte Claude. C'est à faire une seule fois.

Ces commandes viennent de la documentation officielle d'Anthropic. Ne colle jamais dans ton terminal une commande d'installation trouvée ailleurs.

Tes premiers essais

Tu lui parles en français, normalement. Quelques idées pour commencer :

Crée un fichier liste-courses.txt avec 10 idées de repas rapides pour la semaine.
Range les fichiers de ce dossier dans des sous-dossiers par type.
Explique-moi ce que contient ce dossier.

Avant de modifier quoi que ce soit, il te montre ce qu'il va faire et te demande ton accord. Lis, puis valide.

Les commandes à connaître

CommandeCe qu'elle fait
claudeLance Claude Code dans le dossier où tu es
claude -cReprend ta dernière conversation
/helpAffiche l'aide
/clearRepart d'une conversation vide
/exitQuitte Claude Code
Maj + TabChange le niveau d'autonomie (demander avant d'agir, ou non)

Les trois règles de sécurité

  1. Commence dans un dossier de test, jamais directement dans tes documents importants.
  2. Lis avant de valider. Il te demande la permission, ce n'est pas pour la forme.
  3. Fais une copie de ce qui compte avant de lui confier un vrai dossier.
