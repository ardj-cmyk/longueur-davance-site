Où récupérer Claude, les liens officiels

Claude est gratuit pour commencer, et il marche partout : dans ton navigateur, sur ton ordinateur et sur ton téléphone. Voici les étapes, et uniquement les liens officiels.

Les étapes

  1. Crée ton compte sur claude.ai, avec ton adresse mail ou ton compte Google. C'est gratuit, aucune carte bancaire demandée.
  2. Commence dans ton navigateur. Rien à installer, tu peux poser ta première question tout de suite.
  3. Installe l'application sur ton ordinateur si tu l'utilises souvent : claude.com/fr/download, version Mac ou Windows.
  4. Installe l'application sur ton téléphone : iPhone (App Store) ou Android (Google Play).
  5. Connecte-toi avec le même compte partout. Tes conversations te suivent d'un appareil à l'autre.

Attention aux fausses applis

Une seule sourceLe vrai Claude est édité par Anthropic. Télécharge-le uniquement depuis claude.com ou depuis les stores officiels, avec Anthropic comme éditeur. Les applis « Claude IA chat » d'autres éditeurs ne sont pas Claude. Vérifie toujours le nom de l'éditeur avant d'installer.

Gratuit ou payant ?

Le gratuit suffit pour découvrir : discuter, rédiger, chercher sur le web. Le forfait Pro (18 € par mois, 15 € à l'année) débloque plus d'usage, le modèle Opus et Claude Code.

Le comparatif complet, chiffré : Gratuit, Pro ou Max.
