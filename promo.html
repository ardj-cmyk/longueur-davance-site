Les codes promo avec Claude

Claude cherche les codes, les teste un par un dans ton panier, et te prévient sur Telegram dès qu'un code fait vraiment baisser le total. Toi, tu payes. Voici exactement comment je fais, et la consigne à copier.

1Ce qu'il te faut

  • Un forfait Claude payant (Pro, environ 18 € par mois).
  • L'extension Claude pour Chrome. Incluse dans tous les forfaits payants (Pro, Max, Team, Enterprise), pas dans le gratuit. Elle marche dans Google Chrome, sur ordinateur.
  • Telegram, gratuit, pour être prévenu sur ton téléphone.

2Créer ton bot Telegram (deux minutes)

  1. Dans Telegram, cherche @BotFather (le compte officiel, avec le badge bleu) et écris-lui /newbot.
  2. Donne un nom à ton bot, puis un identifiant qui finit par « bot » (par exemple « mespromos_bot »).
  3. BotFather te répond avec un jeton (une longue suite de chiffres et de lettres). Garde-le de côté.
  4. Ouvre la conversation avec ton nouveau bot et envoie-lui « bonjour ».
  5. Dans Chrome, ouvre cette adresse en remplaçant TON_JETON :
    https://api.telegram.org/botTON_JETON/getUpdates
    Repère "chat":{"id": suivi d'un nombre : c'est ton numéro de conversation.

Le jeton ne donne accès qu'à ton bot, pas à ton compte Telegram ni à tes messages. Ne le publie quand même nulle part : avec lui, n'importe qui peut écrire au nom de ton bot.

3Remplir ton panier, sans payer

Va sur le site, connecte-toi si tu as un compte, et mets dans le panier ce que tu veux vraiment acheter. Pas encore décidé ? Fais la liste des produits, toutes marques confondues, et donne-la à Claude.

4La consigne à copier

Sur l'onglet de ton panier, ouvre Claude (l'icône de l'extension), et colle en remplaçant TON_JETON et TON_NUMERO :

Je suis sur mon panier. Ne paie rien, ne valide aucune commande,
ne saisis aucune information de paiement.
1. Note le total actuel du panier, frais de port compris.
2. Cherche tous les codes promo de cette marque : sur le web
   (sites de codes compris), sur son compte Instagram et son compte X,
   et chez les influenceurs qui travaillent avec elle.
3. Teste les codes un par un dans le champ « code promo ».
   Retire le code précédent avant chaque essai.
4. Ne te fie jamais au message « code appliqué » : regarde le total.
   S'il ne baisse pas, le code ne marche pas, passe au suivant.
5. Garde dans le panier le code qui donne le plus petit total.
6. Dès qu'un code fait baisser le total, préviens-moi en ouvrant
   dans un nouvel onglet :
   https://api.telegram.org/botTON_JETON/sendMessage?chat_id=TON_NUMERO&text=
   suivi du code et du nouveau total.
7. À la fin, fais-moi un tableau : code, où tu l'as trouvé, total obtenu.

Claude te demande l'autorisation avant d'agir sur un nouveau site : accepte pour le site de la marque. Reste à côté pendant qu'il travaille, et ne lui donne jamais tes coordonnées bancaires. C'est toujours toi qui payes.

5Ce que mon test m'a appris

  • Mon panier du 29/10 : 3 pots de whey de 1 kg chez Nutrimuscle, 212,85 € affichés. La promo du site retire 31,92 €, le code d'influenceur trouvé par Claude 9,04 € de plus. Total : 171,89 €.
  • Le chiffre annoncé n'est pas le vrai. Les codes étaient annoncés à 10, 15 ou 20 % sur les sites de codes. Dans le panier, ils donnaient tous 5 %.
  • Il n'y a pas toujours de code. Sur le pot de 4 kg, aucun ne passait (« valide, mais non applicable »). Chez certaines marques, les remises sont liées à ton compte (étudiant, anniversaire, livraison).
  • Les codes ne se cumulent pas entre eux, mais un code peut s'ajouter à la promo du site. D'où l'intérêt de tester sur le vrai panier.

Mes règles

  1. C'est toujours moi qui paie. Claude cherche et teste, il ne valide jamais la commande.
  2. Le total fait foi, jamais le message du site.
  3. Un code réservé à quelqu'un d'autre, on ne force pas. Je ne garde que les codes publics.
