Des exemples de hooks utiles

Un hook, c'est un réflexe : « à chaque fois que ça se passe, fais ça ». Tu le règles une fois, Claude Code l'exécute à chaque fois. La différence avec une règle : une règle, Claude peut l'oublier. Un hook, non. C'est mécanique.

Règle ou hook ?

Ce que dit AnthropicTon fichier CLAUDE.md, Claude le prend comme du contexte, pas comme une obligation. Pour bloquer une action quoi que Claude décide, la documentation renvoie vers un hook. Les hooks sont une fonction de Claude Code, donc d'un forfait payant.

1Le plus simple : demande-le à Claude

Pas besoin de savoir coder. La documentation officielle le dit : tu peux décrire le hook voulu à Claude, il l'écrit pour toi. Trois demandes à copier dans Claude Code :

Crée-moi un hook qui m'envoie une notification sur mon Mac
quand tu attends une réponse de ma part.
Crée-moi un hook qui bloque toute modification du fichier .env
et du dossier .git, et qui t'explique pourquoi.
Crée-moi un hook qui, avant chaque commande d'installation
(npm install, pip install, brew install), t'arrête
et t'oblige à vérifier l'outil d'abord.

Ensuite, tape /hooks : tu vois tous tes hooks, rangés par moment de déclenchement.

2Cinq hooks utiles

  • Être prévenu quand Claude attend. Une notification dès qu'il a besoin de toi. Tu fais autre chose pendant qu'il travaille.
  • Protéger tes fichiers sensibles. Avant chaque modification, le hook vérifie le fichier visé. Si c'est .env ou .git, il bloque.
  • Vérifier avant d'installer. Le réflexe de la vidéo : aucune installation sans audit d'abord.
  • Remettre en forme après chaque modification. Ton code reste propre sans que tu y penses.
  • Rappeler tes consignes après un résumé. Quand la conversation est compactée, des détails se perdent. Le hook réinjecte l'essentiel. Le pourquoi : l'antisèche du contexte.

3À quoi ça ressemble

L'exemple de la documentation officielle, la notification sur Mac, à placer dans ~/.claude/settings.json :

{
  "hooks": {
    "Notification": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "osascript -e 'display notification \"Claude Code needs your attention\" with title \"Claude Code\"'"
          }
        ]
      }
    ]
  }
}
  • ~/.claude/settings.json : le hook vaut pour tous tes projets.
  • .claude/settings.json dans un dossier : il vaut pour ce projet seulement.

Les 3 précautions

  1. Un hook a tous tes droits. D'après Anthropic, il peut modifier, supprimer ou lire n'importe quel fichier de ton compte. Relis-le et teste-le avant de l'adopter.
  2. Un hook trouvé sur internet se vérifie comme un skill : la méthode.
  3. Dossier inconnu, prudence. Claude Code ne lance les hooks d'un dossier qu'après que tu as accepté de lui faire confiance. Ne clique pas « oui » par réflexe.
